# 标注系统 - 部署文档

## 系统简介

基于 Python 标准库的轻量级数据标注系统，无需安装任何第三方依赖。

- 后端：Python HTTP Server（端口 8000）
- 前端：纯 HTML/JS/CSS（端口 5173）
- 数据库：SQLite（用户认证）
- 两种部署模式：开发模式（直连）和生产模式（Nginx 反向代理）

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Ubuntu 20.04+ / CentOS 7+ / Debian 11+ |
| Python | 3.8+（仅需标准库，无需 pip install） |
| 端口 | 开发模式: 8000+5173；生产模式: 80 |
| 内存 | 512MB+ |

---

## 二、快速部署

### 1. 上传到服务器

```bash
scp -r version1/ ubuntu@你的服务器IP:/home/ubuntu/label-system
```

### 2. 启动服务

```bash
cd /home/ubuntu/label-system

# 开发模式（直连，适合调试）
./start.sh

# 生产模式（Nginx 反向代理，推荐）
./start.sh --prod
```

### 3. 访问系统

- 开发模式：`http://你的服务器IP:5173`
- 生产模式：`http://你的服务器IP`（80 端口）

**初始账号**：`admin` / `admin`

---

## 三、后台运行

### 方式一：start.sh --prod（推荐）

```bash
cd /home/ubuntu/label-system
./start.sh --prod
```

自动处理 Nginx 安装、配置、服务启动。

### 方式二：systemd（后端常驻）

```bash
# 复制服务文件
sudo cp label-system.service /etc/systemd/system/
# 编辑 WorkingDirectory 为实际路径
sudo systemctl daemon-reload
sudo systemctl enable label-system
sudo systemctl start label-system

# 查看状态/日志
sudo systemctl status label-system
sudo journalctl -u label-system -f
```

## 四、防火墙配置

### 云服务器安全组（必须）

- 生产模式：放行 **TCP 80**
- 开发模式：放行 **TCP 5173** 和 **TCP 8000**

### 系统防火墙

```bash
# UFW（Ubuntu）
sudo ufw allow 80/tcp    # 生产模式
sudo ufw status

# firewalld（CentOS）
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --reload
```

## 五、更新代码

```bash
# 1. 停止服务
pkill -f "backend.main"
```

## 七、常见问题

### Q1: 启动后浏览器无法访问

1. 确认服务器安全组已放行 **TCP 8000**
2. 确认防火墙已开放 8000 端口
3. 测试后端是否正常：`curl http://127.0.0.1:8000/api/health`
4. 确认绑定地址为 `0.0.0.0`（不是 `127.0.0.1`）

### Q2: 端口被占用

```bash
# 查看占用
ss -tlnp | grep 8000

# 杀掉进程
kill -9 <PID>
```

### Q3: Command 'python3' not found

```bash
sudo apt update
sudo apt install python3 -y
```

### Q4: 忘记 admin 密码

```bash
cd /home/ubuntu/label-system
# 删除数据库重新初始化（会丢失用户数据，标注数据不受影响）
rm label_system.db
python3 -m backend.main
# 初始账号恢复为 admin/admin
```

### Q5: 注册后无法登录

新注册用户需要 admin 审批后才能登录。用 admin 账号进入「用户管理」页面审批。

### Q6: Connection reset by peer 错误

这是端口扫描器或健康检查导致的正常现象，不影响使用，可忽略。

## 八、目录结构

```
label-system/
├── backend/              # 后端代码
│   ├── main.py           # 启动入口
│   ├── server.py         # HTTP 路由
│   ├── datastore.py      # JSONL 数据缓存
│   ├── db.py             # 用户数据库
│   ├── config.py         # 路径和端口配置
│   ├── image_server.py   # 图片服务
│   ├── record_utils.py   # 记录摘要和统计
│   └── utils/datasets.py # 数据解析工具
├── frontend/             # 前端页面
│   ├── index.html
│   ├── app.js
│   └── styles.css
├── data/                 # 图片目录（按 checkpoint 分类）
├── jsonl/                # JSONL 标注数据
├── start.sh              # 启动脚本（支持 --prod）
├── stop_all.sh           # 停止脚本
├── status.sh             # 状态检查
├── nginx.conf            # Nginx 配置
├── label-system.service  # systemd 服务配置
└── label_system.db       # SQLite 用户数据库
```
